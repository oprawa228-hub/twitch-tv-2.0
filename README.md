# Twitch 2.0

Самостоятельное приложение Android TV от Oprawa. Новая реализация на Kotlin и Compose for TV; прежнее приложение устанавливается рядом и использует отдельный канал обновлений.

**Доступна beta.11 для Android TV.**

## [⬇️ Скачать APK](https://github.com/oprawa228-hub/twitch-tv-2.0/releases/download/v0.1.0-beta.11/Twitch20-0.1.0-beta.11.apk)

Это не официальный клиент Twitch.

Работают каталог и поиск, категории и страница канала, вход по коду и отслеживаемые каналы, эфиры/записи/клипы, качество и перемотка, сохранение позиции, чат в двух режимах, настройки с анимированными примерами и обновление через Android. Проверено в Android TV API30/x86 и API36/x86_64; физический ARM-телевизор пока не проверен.

В beta.11 исправлена причина повторного запуска коммерческой вставки при откате растущего HLS-плейлиста; продолжение после паузы использует актуальный эфир. Индикатор качества показывает формат декодируемого видео. Добавлены отдельный список онлайн-подписок и уведомления о начале эфиров, четыре понятных размера чата и предпросмотры в контексте настроек. [Что изменено, почему и как проверено](docs/DESIGN_BETA11.md). Это не обещание отсутствия рекламы Twitch или исправления всех декодеров телевизоров.

## Установка

Скачайте `Twitch20-0.1.0-beta.11.apk` из Assets выпуска и откройте на Android TV. Приложение появляется в списке приложений телевизора и устанавливается рядом с прежним клиентом. Для входа откройте «Настройки» → «Аккаунт» и подтвердите код на сайте Twitch с телефона/компьютера.

Обновления: «Настройки» → «О приложении» → «Канал: тестовый» → «Проверить обновления» → «Скачать» → «Установить обновление». При первом разрешении установки Android может закрыть приложение. В этом случае откройте Twitch 2.0 снова и повторите проверку/скачивание; данные не удаляются. Установку всегда подтверждает пользователь в системном окне.

## Сборка

JDK 17, Android SDK platform 36/build-tools 35.0.0, Gradle Wrapper 8.13. Укажите `sdk.dir` в локальном `local.properties` либо ANDROID_HOME.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

Для подписанной сборки нужен исключённый из Git `signing.properties` с `storeFile`, `storePassword`, `keyAlias`, `keyPassword`. Существующий ключ релизов хранится отдельно. Не генерируйте другой ключ для обновления уже установленного приложения.

```powershell
.\gradlew.bat :app:assembleRelease '-PreleaseCode=13' '-PreleaseName=0.1.0-beta.11' --no-daemon
```

Пакет `com.oprawa.twitch20`, Android 6/API23 или выше, Android TV и D-pad. Декодирование использует Android MediaCodec; поддержка конкретного кодека определяется устройством. Приложение не включает собственные ABI-зависимые декодеры.

## Управление

Стрелки — перемещение; короткое OK — открыть эфир; долгое OK на карточке или быстром канале — страница канала. Фокус на разделе слева показывает его содержимое; Right/OK переводит управление в каталог. Поиск открывается отдельным действием. Back закрывает вложенную панель/управление, возвращает к каталогу.

В плеере ↑ от Play/Pause переводит фокус на шкалу записи; ←/→ выбирают позицию, OK подтверждает, Back отменяет. ↓ возвращает к Play/Pause. Долгий OK на чате или кинотеатре открывает отдельный профиль. Настройки применяются одним OK; фокус на варианте показывает временный пример, Back отменяет неподтверждённую примерку. Чат и кинотеатр взаимно исключаются, но сохраняют независимые настройки.

## Twitch и приватность

Каталог после входа использует официальный Helix. Гостевой каталог и источники видео используют изолированную недокументированную интеграцию GQL/Usher. Twitch может изменить или ограничить её. Официальный Device Code Flow используется для аккаунта и отслеживаемых каналов. Подписочные записи и специальные права просмотра не подтверждены этим способом входа.

Client ID приложения публичен. Пароли, клиентский секрет и токены в исходниках отсутствуют. Пользователь подтверждает вход на Twitch; токены зашифрованы Android Keystore и исключены из резервного копирования. История позиций ограничена 100 элементами, чат — 150 сообщениями; переписка не сохраняется.

## Обновления

Меню «Настройки» → «О приложении» проверяет GitHub, загружает APK и передаёт его штатному установщику Android. Проверяются SHA-256, пакет, версия, Android API и сертификат подписи. Пользователь подтверждает установку. Тестовый канал включает предварительные релизы; обычный использует GitHub Latest. При HTTP 403/429 используются закреплённые публичные `updates/test.json` и `updates/stable.json`; APK остаётся неизменяемым файлом конкретного релиза. Личный GitHub-токен не нужен. Стабильный выпуск пока не объявлен, поэтому обычный канал может сообщать об отсутствии обновлений.

## Границы бета-версии

- После входа эфиры, категории, записи и клипы подгружаются при прокрутке. Предел — 1000 элементов на каталог, кэш — три каталога. Гостевой каталог ограничен первой страницей (30–40 элементов): Twitch блокирует продолжение. Отслеживаемые каналы имеют отдельный предел 2000.
- Twitch может менять недокументированный доступ к публичному видео. Подписочные записи, Turbo и обход рекламы не обещаются.
- Дополнительные эмоты и отправка чата не включены. Предпросмотр видео работает без звука; уведомления о новых эфирах работают внутри открытого приложения, а не как фоновая push-служба.
- Производительность измерена в эмуляторе со SwiftShader; это не оценка аппаратного декодирования реального телевизора.
- На одном канале программный AVC-декодер эмулятора получал ошибку4003; она воспроизведена и в минимальном Media3-плеере без оболочки приложения. На Android TV 16 с другим AVC-декодером тот же канал прошёл продолжительный просмотр и паузы; старый OMX-дефект не объявляется исправленным. Физический TV пока не проверен. Дизайн дорабатывается поэтапно; beta.11 не объявляется окончательным оформлением.
