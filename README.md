# Twitch 2.0

Самостоятельное приложение Android TV от Oprawa. Новая реализация на Kotlin и Compose for TV; прежнее приложение устанавливается рядом и использует отдельный канал обновлений.

**Доступна beta.9 для Android TV.**

## [⬇️ Скачать APK](https://github.com/oprawa228-hub/twitch-tv-2.0/releases/download/v0.1.0-beta.9/Twitch20-0.1.0-beta.9.apk)

Это не официальный клиент Twitch.

Работают каталог и поиск, категории и страница канала, вход по коду и отслеживаемые каналы, эфиры/записи/клипы, качество и перемотка, сохранение позиции, чат в двух режимах, настройки с анимированными примерами и обновление через Android. Проверено в Android TV API30/x86; физический ARM-телевизор пока не проверен.

В beta.9 плеер получил компактные иконки и управляемую шкалу записи: стрелки выбирают позицию, OK подтверждает, Back отменяет; удержание ускоряет. Размер текста выбирается как Маленький / Средний / Большой с временным предпросмотром. Качество открывается на текущем варианте; долгий OK на чате и кинотеатре открывает нужный профиль. **155 модульных тестов и 19 различных Android-сценариев** прошли по отдельным прогонам; настоящий Twitch live/VOD проверен на подписанном APK. [Что изменено, почему и как проверено](docs/DESIGN_BETA9.md). [Полный UI/UX аудит и оставшиеся задачи](docs/UI_UX_CHECKLIST_AUDIT.md).

## Установка

Скачайте `Twitch20-0.1.0-beta.9.apk` из Assets выпуска и откройте на Android TV. Приложение появляется в списке приложений телевизора и устанавливается рядом с прежним клиентом. Для входа откройте «Аккаунт» и подтвердите код на сайте Twitch с телефона/компьютера.

Обновления: «О проекте» → «Канал: тестовый» → «Проверить обновления» → «Скачать» → «Установить обновление». При первом разрешении установки Android может закрыть приложение. В этом случае откройте Twitch 2.0 снова и повторите проверку/скачивание; данные не удаляются. Установку всегда подтверждает пользователь в системном окне.

## Сборка

JDK 17, Android SDK platform 36/build-tools 35.0.0, Gradle Wrapper 8.13. Укажите `sdk.dir` в локальном `local.properties` либо ANDROID_HOME.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

Для подписанной сборки нужен исключённый из Git `signing.properties` с `storeFile`, `storePassword`, `keyAlias`, `keyPassword`. Существующий ключ релизов хранится отдельно. Не генерируйте другой ключ для обновления уже установленного приложения.

```powershell
.\gradlew.bat :app:assembleRelease '-PreleaseCode=11' '-PreleaseName=0.1.0-beta.9' --no-daemon
```

Пакет `com.oprawa.twitch20`, Android 6/API23 или выше, Android TV и D-pad. Декодирование использует Android MediaCodec; поддержка конкретного кодека определяется устройством. Приложение не включает собственные ABI-зависимые декодеры.

## Управление

Стрелки — перемещение; короткое OK — открыть эфир; долгое OK на карточке — страница канала. Back закрывает вложенную панель/управление, возвращает к каталогу. В плеере ↑ от Play/Pause переводит фокус на шкалу записи; ←/→ выбирают позицию, OK подтверждает, Back отменяет. ↓ возвращает к Play/Pause. Долгий OK на чате или кинотеатре открывает отдельный профиль. Настройки показывают пример до сохранения. Back из профиля возвращает в обзор с сохранением черновика; Back из обзора/Отмена отменяет его, Сохранить применяет все изменения.

## Twitch и приватность

Каталог после входа использует официальный Helix. Гостевой каталог и источники видео используют изолированную недокументированную интеграцию GQL/Usher. Twitch может изменить или ограничить её. Официальный Device Code Flow используется для аккаунта и отслеживаемых каналов. Подписочные записи и специальные права просмотра не подтверждены этим способом входа.

Client ID приложения публичен. Пароли, клиентский секрет и токены в исходниках отсутствуют. Пользователь подтверждает вход на Twitch; токены зашифрованы Android Keystore и исключены из резервного копирования. История позиций ограничена 100 элементами, чат — 150 сообщениями; переписка не сохраняется.

## Обновления

Меню «О проекте» проверяет GitHub, загружает APK и передаёт его штатному установщику Android. Проверяются SHA-256, пакет, версия, Android API и сертификат подписи. Пользователь подтверждает установку. Тестовый канал включает предварительные релизы; обычный использует GitHub Latest. При HTTP 403/429 используются закреплённые публичные `updates/test.json` и `updates/stable.json`; APK остаётся неизменяемым файлом конкретного релиза. Личный GitHub-токен не нужен. Стабильный выпуск пока не объявлен, поэтому обычный канал может сообщать об отсутствии обновлений.

## Границы бета-версии

- После входа эфиры, категории, записи и клипы подгружаются при прокрутке. Предел — 1000 элементов на каталог, кэш — три каталога. Гостевой каталог ограничен первой страницей (30–40 элементов): Twitch блокирует продолжение. Отслеживаемые каналы имеют отдельный предел 2000.
- Twitch может менять недокументированный доступ к публичному видео. Подписочные записи, Turbo и обход рекламы не обещаются.
- Дополнительные эмоты, отправка чата, мини-видео на карточках и уведомления не включены.
- Производительность измерена в эмуляторе со SwiftShader; это не оценка аппаратного декодирования реального телевизора.
- На одном канале программный AVC-декодер эмулятора получал ошибку4003; она воспроизведена и в минимальном Media3-плеере без оболочки приложения. Причина сочетания потока/Media3/decoder не установлена, физический TV пока не проверен. Дизайн дорабатывается поэтапно; beta.9 не объявляется окончательным оформлением.
