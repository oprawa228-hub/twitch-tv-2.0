# Backend beta4 — отчёт этапа

Состояние на **2026-11-08**. Работа сосредоточена на данных, пагинации и жизненном цикле авторизации. Дизайн явно отложен по решению пользователя.

## Что изменено

- Каталог после входа использует официальный Helix: эфиры, категории, записи и клипы загружаются страницами. Реальные гостевые GQL-запросы продолжения получили `IntegrityCheckFailed`; обход не выполнялся. Гостю доступна первая выдача с явным пояснением ограничения.
- `CatalogPager` сохраняет карточки при ошибке, позволяет повторить запрос, исключает дубликаты и защищает состояние от отменённых/устаревших ответов. Для пустых страниц с продолжением установлен предел трёх последовательных запросов. Каталог ограничен 1000 элементами; кэш хранит три каталога с вытеснением давно не использованных.
- Маршрутизация каталогов подключена к кэшу. После ревью исправлены устаревшие сведения о канале при обновлении и восстановление фокуса при смене поколения/экземпляра загрузчика.
- После запуска без сети сохранённая сессия повторно проверяется через 60 секунд; исправная сессия — каждый час. Обновление токенов и сохранение результата защищены от отмены в пределах 30 секунд; выход из аккаунта не позволяет позднему ответу восстановить завершённую сессию.
- OAuth остаётся в авторизованном транспорте Helix. Гостевой GQL и получение источников воспроизведения отделены от этого транспорта.

## Проверено

Root подтвердил **72 успешных JVM-теста**: прежние 42, загрузчик страниц 9, Helix-каталог 11, жизненный цикл авторизации 5, доступ к Helix 5. Локальные свидетельства: `evidence/build-beta4.log` и `evidence/beta4-focus-fix-build.log`.

На основном эмуляторе **5560** с сохранённой сессией **oprawa** прошли шесть Android-сценариев debug APK, включая прокрутку за первые 30 эфиров и возврат на ту же карточку/строку после страницы канала. В полном диагностическом прогоне `evidence/instrumentation-beta4-final.log` шесть успешных сценариев соседствовали с неуспешной попыткой проверить refresh: долгоживущий accessibility-сеанс не видел фокус после замены каталога, хотя свежие внешние XML и снимки его показывали. Этот сценарий перенесён в `tools/qa_catalog_refresh.py`: реальный D-pad, свежие UI Automator снимки, без кликов/подмены фокуса. Проверка на канале buster прошла: кнопка обновления вернула фокус на прежнюю запись (`evidence/beta4-native-refresh.log`, `beta4-refresh-before-final` и `beta4-refresh-restored-final`). Проверен debug APK; это не утверждение о семи успешных instrumentation-тестах.

Подписанный minified release собран после исправлений (`evidence/beta4-final-build.log`) и установлен поверх прежних данных через ADB. На нём холодный запуск без Wi-Fi показал сетевую ошибку; после включения Wi-Fi аккаунт восстановился автоматически через **59 секунд**, каталог загрузился без нового входа (`evidence/beta4-offline-recovery.log`, `beta4-offline-start` / `beta4-offline-recovered`). Попытка запустить debug-targeted instrumentation поверх R8-release несовместима по classpath (`kotlin.jvm.internal.Intrinsics`); она не считается release-проверкой. Release проверяется отдельными внешними D-pad сценариями.

Кандидат: **0.1.0-beta.4, versionCode 6**, пакет `com.oprawa.twitch20`, SHA-256 `c1a96eb236957454840fb3e95ce18cefd4061214d6209b87606eaffc476e146b`, прежний сертификат `f81f51fd47d318aaf79f1fe3c81159fe6eca405f881f4f0b19d097d1c4b006f7`. Публикация и OTA отмечаются ниже отдельно. Сырые журналы и прочие локальные свидетельства не предназначены для Git.

## Оставшиеся ограничения

После переноса refresh в отдельный нативный сценарий финальный полный instrumentation-прогон завершён: **OK (6 tests), 79.751с**, `evidence/instrumentation-beta4-six.log`. Проверен debug beta.4/code6. Настройки тесты возвращают в исходное состояние.

Сеть следующей страницы проверена на точном release APK: Wi-Fi отключён после первой страницы, пультом пройдены 10 первых карточек строк (30 элементов); старые карточки остались, появилась «Повторить загрузку». Первый повтор во время восстановления соединения ещё вернул сетевую ошибку; следующий явный повтор загрузил страницу. Up перевёл фокус на новую карточку TheWhelps после прежних 30. Свидетельства: `beta4-page-offline-retained`, `beta4-page-retry-second`, `beta4-page-retry-new-card`. Первоначальный автоматический таймаут зафиксирован в `evidence/beta4-catalog-network.log`; завершение подтверждено последующими реальными D-pad действиями. Скрипт `tools/qa_catalog_network.py` теперь допускает до трёх явных повторов при восстановлении Wi-Fi; эта редакция скрипта отдельно полностью не прогонялась.

- Гостевая пагинация блокируется внешним сервисом. Нельзя считать первую гостевую выдачу полным каталогом.
- Предел 1000 элементов в приложении является явной границей памяти. Helix отдельно ограничивает выдачу клипов примерно 1000 результатами на временной диапазон; это не полный архив. Недельное окно клипов фиксируется на время жизни экземпляра репозитория.
- Рейтинг эфиров меняется между запросами: дедупликация предотвращает повтор карточек, но не гарантирует неизменный снимок всего Twitch.
- Fixture/JVM, гостевая сеть, личная сессия, эмулятор и физический TV — разные уровни проверки. Этот этап не подтверждает физический TV, реальные отзыв/обновление токена в длительной сессии или права просмотра закрытого контента.
- Итог Android-прогона, проверка релизного APK и публикация остаются отдельными незавершёнными шагами root. Визуальная переработка в этот этап не входит.
