# Нативная игровая сцена beta8

Сцена — явно обозначенный пример видео для настройки чата. Авторская графика сохраняет узнаваемые танк и персонажа, но движение полностью новое: отдельные векторные слои, Compose `graphicsLayer`, Canvas. WebView, CSS-движок и старый код приложения не используются. Фон и рамка камеры неподвижны; весь прямоугольник не пульсирует. Сцена не содержит кнопок, не перехватывает D-pad и не задерживает изменение настроек.

## Контракт

`internal @Composable PreviewScene(animationsEnabled: Boolean, modifier: Modifier = Modifier)` — 16:9 fit внутри переданного ограниченного контейнера. В settings-preview она представляет только видео; чат, часы и подпись «Пример» рисует вызывающий экран по общей геометрии настоящего плеера. `rememberPreviewMotionEnabled(animationsEnabled)` даёт вызывающему экрану общий разрешающий флаг для таймера примера сообщений.

## Раскадровка: цикл 8 секунд

| Время | Действие | Связь |
|---|---|---|
| 0–1,2 с | Спокойный кадр | Фон и рамка всегда неподвижны |
| 1,2–2,1 с | Танк проезжает 13 единиц в сцене 640×360; спицы поворачиваются по расстоянию | Корпус, башня и колёса движутся согласованно |
| 2,2–2,61 с | Отдача башни до 10 единиц; небольшой дым рассеивается за 0,6 с | Видимая причина следующей реакции |
| 2,21–4,83 с | Три сердечка разного размера от дула изгибаются вверх и влево, в свободное небо над танком, плавно исчезают | Короткая очередь после выстрела, без мерцания; основной полёт виден слева от стандартного чата TOP_RIGHT |
| 2,3–3,36 с | Персонаж слегка отклоняется на 4°, гарнитура подпрыгивает на 7 единиц и садится обратно | Реакция на выстрел; рамка камеры остаётся на месте |
| 4,3–5,55 с, каждый третий цикл | Кружка поднимается в коротком тосте на 9° | Редкая визуальная шутка, без новых баннеров и надписей |
| 5,4–6,5 с | Танк спокойно возвращается | Конец совпадает со стартовой позой |
| 6,5–8 с | Пауза | Следующий цикл не начинается с резкого скачка |

Движение по экрану использует кривую cubic-bezier(0.77, 0, 0.175, 1); отдача/реакции — cubic-bezier(0.23, 1, 0.32, 1). Это длительная игровая иллюстрация, а не анимация открытия меню: правила длительности UI-переходов к ней не применяются. Навигация пультом остаётся независимой. Skills animate, review-animations и choreograph использованы для причинно-следственной последовательности, неподвижных опор, ограниченного количества движения и проверки остановки; браузерные требования не переносились.

## Остановка и ресурсы

- App `animationsEnabled=false` или системный `Settings.Global.ANIMATOR_DURATION_SCALE=0` показывают спокойный статичный кадр. Неположительные/нечисловые scale также запрещают кадры. Положительный системный scale изменяет скорость сцены.
- Кадровый цикл существует только в lifecycle `RESUMED`, пока Android view прикреплён, видим и имеет фокус окна, и сама сцена пересекает окно. На `PAUSED`, уходе из composition, потере фокуса/видимости либо выключении движения `LaunchedEffect` отменяется. Нет независимых таймеров слоёв и цепочек, способных продублироваться.
- При возврате начинается один новый спокойный цикл. На большой кадровой паузе шаг ограничен 100 мс, чтобы не перескакивать через всю сцену.
- Внутреннее перекрытие произвольным непрозрачным Compose-слоем нельзя определить по Android visibility: вызывающий экран должен убрать PreviewScene из composition при его полном скрытии. Текущая модальная навигация settings это делает. Частично видимая сцена может продолжать движение.
- SVG-запросы запоминаются, кадровое состояние читают только слои/Canvas; композиция всего экрана на каждом кадре не требуется. Сам Canvas с тремя сердечками и шестью колёсами всё же перерисовывается — производительность на физическом TV ещё не измерена.

## Проверка и честные ограничения

6 JUnit-тестов `PreviewMotionTest` проверяют запреты движения, начальную/конечную позу, выстрел/сердечки, редкость тоста, ограничения координат/скачков на трёх циклах и видимость сердечек вне стандартного TOP_RIGHT overlay. RED исходных пяти подтверждён root в `evidence/beta8-motion-red.log`; итог GREEN и сборку выполняет root. Экстракция восьми SVG выполнена без изменений исходного проекта.

После нативного кадра `evidence/android/beta8-final-motion-shot.png` исправлена композиция: прежний полёт вправо почти целиком скрывался чатом. Новая траектория начинается в той же точке дула (491, 189), но уходит по небольшой дуге влево к x=371. Регрессия проверяет не только центр: с возраста 900 до 1900 мс весь сердечный силуэт с запасом 22×scale располагается левее границы чата x≈475, пока alpha>0,9. Начало выстрела у дула всё ещё может частично перекрываться чатом; траектория не меняется при переключении режима и не пытается обходить все четыре положения overlay. Геометрия чата сохранена.

Нативная приёмка root: записать ≥24 с, проверить обычный цикл и редкий тост; переключить app motion off на середине выстрела; включить system scale 0 и обратно; Home → возврат и About → Back несколько раз; убедиться, что статичный кадр действительно неподвижен, дублирующихся сердечек нет, края камеры не выпускают части персонажа, а overlay/theater и часы не меняют геометрию из-за иллюстрации. Варианты системной скорости/слабый TV требуют проверки; эта реализация сама по себе не является доказательством 60 FPS на физическом устройстве.
