## Что меняется и почему

- Индикатор качества берёт текущий формат видеодекодера. Раньше обход ABR-группы перезаписывал значение последней доступной дорожкой160p, даже если декодировалось720p. Рекламная вставка также может иметь другое фактическое разрешение, чем вариант master-плейлиста.
- Кнопка качества снова44×44dp, как соседние действия. Краткая подпись разрешения остаётся на кнопке, а выбранный режим Авто/ручной виден в списке качеств.
- Поиск отделён сверху. Далее Каналы, Записи, Категории, Рекомендации; внизу только Настройки. Аккаунт и О приложении остаются внутри настроек.
- Онлайн-каналы подписок имеют собственный прокручиваемый список с аватарами. Обновление зрителей не переставляет выбранный пункт; исчезновение канала восстанавливает соседний фокус. Устойчивый фокус показывает предпросмотр, OK/Right запускает эфир, длинный OK открывает канал.
- Одна загрузка подписок обслуживает каталог, боковую панель и уведомления. Она работает только в foreground:30сек после успешного ответа,10сек после ошибки. Ошибка сохраняет последний список и базу уведомлений.
- Уведомление возникает на новый идентификатор эфира, а не на изменение заголовка/зрителей. Первоначальная загрузка молчит; текущий канал исключается; настройки, HUD и фон откладывают свежие события. Баннер не забирает фокус, виден4.5сек; очередь ограничена, ожидание20сек. Интервалы не зависят от изменения часов телевизора.
- Четыре стандартных размера шрифта14/16/18/22 названы Маленький, Компактный, Средний, Большой. Старые нестандартные значения сохраняются точно и подписываются «Размер N». Название не обещает отсутствующий редактор произвольного размера.
- Предпросмотр показывает контекст параметра: каталог для карточек/часов, настоящий ChatPanel для чата, общий компонент баннера для уведомлений. Уменьшенная сцена чата дополнена образцом текста в настоящем размере.

Подробности и решения: [навигация](NAVIGATION_BETA11.md), [настройки](SETTINGS_BETA11.md), [воспроизведение](COMMERCIAL_PLAYBACK_BETA11.md).

## Границы каталога записей

Раздел Записи постепенно загружает последние три архивных трансляции каждого отслеживаемого канала, по шесть каналов за запрос страницы. Он использует зафиксированный список подписок на время пагинации. Записи упорядочиваются по времени внутри загруженной группы; глобальный временной порядок всех подписок не обещается. Полный архив конкретного канала доступен на его странице.

Пустые группы не зацикливают загрузку и не превращаются в ошибку сервера: после ограниченного сканирования доступно «Искать дальше». Для персонального раздела нужен вход в Twitch.

## Что не обещается

Начальная реклама Twitch может оставаться. Плейлисты и рекламные сегменты не вырезаются. Ограниченная отсрочка Stuck действует только при подтверждённом росте ранее укороченного рекламного плейлиста, максимум60с; обычная остановка не скрывается.

На старом API30 `OMX.google.h264.decoder` отдельная ошибка4003 воспроизведена и в минимальном Media3 плеере. Отключение adaptive reuse её не устранило. Автоматический reprepare после decoder fatal удалён: он повторно загружал начальное окно и давал долгую буферизацию. На TV16 с другим декодером проблема не повторилась; физический ARM TV пока не проверен.

Финальный playback-прогон на TV16:18/18 PASS за213,865с (vidence/beta11-final-playback-native.log), включая два новых production Goldfish сценария. Вместе с предыдущими прогонами —69 различных native сценариев PASS. Публичные файлы и обычное OTA подтверждены в разделе доставки выше.

### Финальная визуальная регрессия Goldfish

На TV16 после1080p рекламного кадра→720p видео занимало левый верхний прямоугольник853×480, а снаружи оставались старые пиксели. Логи codec сообщали прежний output1920×1080. Ограниченный контроль disableAdaptive для точного имени c2.goldfish.h264.decoder дал REUSE_NO при смене разрешения и визуально полный кадр, без нового HLS master. Production применяет этот обход только к Goldfish; остальные кодеки сохраняются. При этом старый OMX4003 повторился на Caedrel после42с и остаётся отдельным ограничением (eta11-signed-primary-caedrel.log).

Подписи сфокусированных кнопок качества и часов теперь также обновляются при изменении значения: прежний текст не остаётся до следующего перемещения фокуса.
