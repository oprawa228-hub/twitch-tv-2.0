### Следующий этап — цельный телевизионный интерфейс

Уточнение пользователя: «Чат» означает оверлей. Включение оверлея выключает кинотеатр, включение кинотеатра выключает оверлей; повторное нажатие выключает выбранный режим. Допустимы только OFF/OVERLAY/THEATER. Размер текста и фон сохраняются независимо для двух режимов. Приоритет текущей реализации — исправить этот подтверждённый конфликт во всех точках управления, мигрировать beta.6 без потери предпочтений и проверить draft/Back/save/restart; параллельно выполнить ограниченную доработку каталога. Глобальные настройки и панель плеера используют одни элементы редактирования. Изменение параметров неактивного режима само по себе его не включает; глобальный пример явно подписывает показываемый режим.

План уточнён 2026-11-08 по просьбе пользователя обдумать дальнейшую работу. База — опубликованная beta.6/code8.
