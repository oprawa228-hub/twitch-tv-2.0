## Что изменено

Вход теперь применяется и к live-видео, и к предпросмотрам карточек/боковой панели. Свежий источник предпросмотра передаётся в плеер один раз, максимум в течение 60 секунд, только для того же канала и аккаунта. Повторные попытки получают новый источник; отменённые запросы не оставляют кэш. При ошибке авторизации нет скрытого перехода на гостевой источник.

В release включён явно заданный `legacyTvClientId` — тот же публичный TV Client ID, который проверен в старом клиенте и локальном test.2. Вход подтверждается только на Twitch; название в запросе доступа может принадлежать телевизионному клиенту Twitch. Это экспериментальная совместимость с внешним video endpoint, не обещание официальной поддержки Twitch. При обновлении с beta.11 нужен новый вход: токен собственного Client ID нельзя превратить в токен другого клиента. Настройки и история не очищаются.

Рекламные сегменты не фильтруются, сторонний прокси не используется. Нет гарантии отсутствия рекламы на всех каналах или будущих midroll.
