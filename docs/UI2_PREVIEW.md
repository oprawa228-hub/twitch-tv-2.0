## Внешние данные и ограничения

- Обложка канала — реальное `offline_image_url`/`offlineImageURL`, если Twitch его предоставляет. Отсутствующая обложка не заменяется выдуманным баннером.
- Авторский Go Live текст получаем отдельным необязательным GQL-запросом `broadcastSettings.liveUpNotificationInfo`. В старом 1.0 найден тот же источник; свежий публичный запрос Monstercat подтвердил наличие поля и пользовательского текста. Официальные Helix/EventSub такого поля не дают. Таймаут/ошибка → «Начал трансляцию», без подмены заголовком стрима.
- Storyboard зависит от наличия данных у Twitch. Проверены пять реальных VOD Shroud и два JPEG-листа 1100×1240. Изображение не генерируется и не подставляется из другой записи.
- Описание обновления берётся из GitHub release body только после проверки соответствующего манифеста. Во время локальной приёмки code15 ещё не был опубликован, поэтому экран корректно показывал отсутствие описания. После публикации описание выпуска доступно через GitHub.
- Изменения этой сборки не устраняют коммерческие вставки Twitch. Сообщённая после beta.12 проблема остаётся отдельной открытой задачей. Сохранён уже существующий авторизованный путь видео; способ входа в этом UI-проходе не заменялся.
