# Аудит Twitch 2.0 для Android TV

Обзор beta.13-preview.5 охватывает навигацию пультом, поиск, live и записи, аккаунт и обновления. Основной сценарий проверен на гостевом Twitch20Release с Android TV API 30. Для остальных выводов в таблице указана основа проверки.

| Приоритет | Сценарий и результат | Доказательство | Что изменить |
| --- | --- | --- | --- |
| Высокий | «Категории» → вправо → ниже до левого края сетки → влево. Вместо «Категорий» выделяются «Рекомендации» и заменяют содержимое. | Воспроизведено в preview.5. `evidence/android/focus-before-categories-*.png`. | Переходить к исходному разделу, сохранять вложенный экран и карточку. Вверх и вниз использовать внутри текущей области. |
| Высокий | Открыть поиск из каталога, отправить запрос и нажать Back с выдачи. Отправка запроса очищает историю, после чего Back может открыть диалог выхода. | Исходники [MainActivity](../app/src/main/java/com/oprawa/twitch20/MainActivity.kt). | Заменять текущую выдачу с сохранением предыдущего экрана. Пустая отправка возвращает начальное состояние поиска. |
| Высокий | На подключённом аккаунте открыть «Аккаунт». Первый фокус стоит на «Выйти», следующий OK сразу сбрасывает вход. | Путь подтверждён по исходникам [AccountScreen](../app/src/main/java/com/oprawa/twitch20/ui/AccountScreen.kt). | Попросить подтвердить выход. Изначально выделить «Остаться» и вернуть фокус после отмены. |
| Средний | В записи включить чат, получить первые реплики и потерять связь во время подгрузки. После восстановления видео чат может остаться на старых репликах без сообщения об ошибке. | Сценарий следует из обработки исключений в [VodChatReplay](../app/src/main/java/com/oprawa/twitch20/ui/VodChatReplay.kt) и показа статуса в [ChatPanel](../app/src/main/java/com/oprawa/twitch20/ui/ChatPanel.kt). Нужна проверка с контролируемым сетевым сбоем. | Повторять запрос с паузой, показывать статус рядом с уже загруженными репликами. |
| Средний | На живом эфире с часами и Overlay справа сверху удержать OK на «Чат». При открытии настройки часы закрывают строку чата. | Видно на архивном кадре code18 `evidence/android/ui3-preview4-live-chat-edit.png`. Причина прослеживается в [PlayerScreen](../app/src/main/java/com/oprawa/twitch20/ui/PlayerScreen.kt). | Привязать чат к границам видео и рассчитывать положение часов по фактической видимости панели. |
| Средний | Из прокрученной выдачи открыть категорию, страницу канала и клипы, затем вернуться трижды. Вытеснение выдачи из кэша также удаляет выбранную карточку и прокрутку. | Правила вытеснения в [MainActivity](../app/src/main/java/com/oprawa/twitch20/MainActivity.kt). Длинная цепочка требует прогона пультом. | Сохранять фокус и прокрутку для экранов в истории независимо от кэша данных. |
| Средний | Поиск возвращает каналы и категории, а запрос записей завершается ошибкой. Фильтр «Записи» показывает пустой результат. | Обработка частичного ответа в [TwitchRepository](../app/src/main/java/com/oprawa/twitch20/data/TwitchRepository.kt). Нужна проверка с контролируемым ответом. | Показывать ошибку у затронутого фильтра и дать повторить запрос. |
| Средний | При входе по QR срок действия кода становится понятен только после истечения. | Дедлайн есть в [TwitchAuth](../app/src/main/java/com/oprawa/twitch20/auth/TwitchAuth.kt), экран [AccountScreen](../app/src/main/java/com/oprawa/twitch20/ui/AccountScreen.kt) его не показывает. | Показать оставшееся время рядом с кодом. |

Обновлять устаревший статус при повторном входе. |
| Низкий | Удержание OK на «Паузе», «Качестве» или «Повторить» поглощает действие. | Обработчик долгого нажатия в [PlayerScreen](../app/src/main/java/com/oprawa/twitch20/ui/PlayerScreen.kt). | На кнопках без отдельного действия удержания выполнить обычное действие один раз при отпускании. |

Все пункты таблицы реализованы в beta.13-preview.7. Каталоги, которые ещё находятся в истории, сохраняют загруженные страницы и позицию. Поиск повторно запрашивает только недоступные разделы. Чат записи показывает состояние восстановления и делает до четырёх повторов с интервалами 1, 2, 4 и 8 секунд. Полное описание выпуска привязано к его версии. Новый резервный манифест содержит тот же текст.

На Android TV API 36 с сохранённым аккаунтом проверены оба способа отменить выход, возврат из предпросмотра закреплённого канала, цепочка поиск → категория → канал → клипы → Back, чтение полного описания и положение часов с Overlay на реальном эфире. На API 30 у гостя подтверждены уменьшение времени жизни QR-кода и возврат после отмены. Снимки в `evidence/android/audit7-*`. Частичные ошибки поиска и восстановление чата при тайм-ауте или сетевой ошибке проверены с контролируемыми ответами в JVM. Физический телевизор в этом проходе не использовался.
