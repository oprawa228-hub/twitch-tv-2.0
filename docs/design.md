# Twitch 2.0 — визуальные правила

## Уточнение направления и motion storyboard — 2026-11-09

Дополнение пользователя при старте реализации: **не копировать Twitch 1.0**. Он показывает удачный характер, но не доказывает, что его компоновка оптимальна. Для beta.8 решения принимаются по сценариям Android TV и проверяемым проблемам; итоговый отчёт объясняет «что изменилось → почему → как проверено». Авторская сцена может использовать разрешённую графику с новой нативной постановкой. Базовая палитра beta.8: фон #0C0D12, поверхность #16171F, поднятая поверхность #242630, вторичный текст #ABB0C0, фокус #C7AEFF, ссылка #C6A3FF. Светлая лаванда отделяет фокус от насыщенного акцента включённого режима; старые значения ниже остаются исследованием источника.

Пользователь подтвердил: сохранить характер Twitch 1.0 с улучшением композиции и читаемости; сделать примеры более живыми и игровыми, с движением персонажей, сердечками и небольшими шутками. Приложение предназначено широкой аудитории Android TV, не одному телевизору. Последовательность реализации и проверки находится только в PLAN.md.

Референсы 1.0.2 сопоставлены с `evidence/android/beta7-final-catalog.png`, `beta7-final-categories.png`, `beta7-ota-settings.png`, `beta7-player-panel.png`. В каталоге сохраняются настоящие обложки и достигнутая сетка. В настройках длинную форму заменят короткие страницы с крупным примером. В плеере останется компактная правая панель с полным видеокадром. Примеры с реальным чатом не публиковать без удаления личного содержимого; для демонстрационного ролика использовать авторские фикстуры.

**Иерархия настроек:** обзор режима → профиль оверлея / профиль кинотеатра / интерфейс; служебные сведения и обновления — отдельные строки. Один общий черновик на сессию. Во вложенном выборе фокус временно примеряет значение; OK переносит его в черновик, Back отменяет локальную примерку. Back между страницами возвращает к обзору с сохранением черновика; Back из корня/«Отмена» отменяет всю сессию, «Сохранить» записывает её. Неактивный профиль остаётся неактивным после редактирования и сохранения его параметров. Быстрые действия HUD по-прежнему применяются сразу.

**Общий визуальный язык:** почти чёрная основа, тёмные поверхности, лавандовый фокус, небольшие скругления, одна шкала текста и отступов. Выбранное значение отмечается отдельно от фокуса. Важное действие имеет текст/значок, состояние не кодируется только цветом. Конкретные начальные размеры ниже уточняются по native-рендеру на нескольких конфигурациях, включая увеличенный шрифт. Декоративные движения сосредоточены внутри примеров; каталог и управление просмотром остаются быстрыми.

| Пример | Постановка | Что должно совпасть с приложением |
|---|---|---|
| Авторская сцена | Ориентир цикла 5,6 с: 0–1,6 с спокойная сцена/подъезд; 1,9–2,4 с отдача, три сердечка с задержкой 140 мс, реакция персонажа; далее полёт/исчезновение и возврат к спокойному кадру. Редкие вариации жеста, кружки и короткой реплики добавят игровой характер | Это декорация внутри примера, она не изображает действие Twitch и не меняет настройку |
| Положение оверлея | Чат переходит между выбранными углами; исходный ориентир 180–210 мс. Следующая стрелка перенаправляет переход из текущей точки | Общие правила размеров и отступов с ChatPanel; видеосцена неподвижна |
| Размер текста | Одни и те же сообщения изменяют размер и переносы; длинный ник/эмодзи/русский текст присутствуют среди примеров | Реальная шкала шрифта и переносы, без масштабирования готового скриншота |
| Фон чата | Изменяется прозрачность панели на светлом и тёмном участке авторской сцены | Та же формула прозрачности и подложка; ники остаются читаемыми |
| OFF / OVERLAY / THEATER | Полная сцена без чата → чат поверх → полное видео слева и отдельная колонка | Всегда только один активный режим; профиль текста/фона независим |
| Неактивный профиль | Открыть кинотеатр при активном оверлее, изменить его параметры и сохранить | «Пример: кинотеатр», «После сохранения: чат поверх видео»; просмотр остаётся в оверлее |
| Анимации | Живой танк/сердечки/сообщения переключаются в выразительный статический кадр | Выключение в приложении и системное отключение движения соблюдаются; параметр всё равно изменяется сразу |

Точные длительности — исходные ориентиры по старому SVG и будущей проверке, не уже измеренный результат. Движущиеся слои управляются нативной временной шкалой; не нужна пульсация всей картинки или встраивание старого JS. Анимации останавливаются при невидимости/уходе в фон. Текст органов управления не движется вместе с иллюстрацией; быстрые нажатия и Back не ждут завершения цикла. Для OFF/OVERLAY/THEATER видеоповерхность получает конечную геометрию без декоративного покадрового изменения размера.

Веб-навыки движения используются как вторичный источник для назначения, прерываемости и качества. Их CSS/hover-рецепты, запрет любого keyboard-motion, обязательные web-библиотеки и ограничение delight только первым запуском не становятся требованиями Android TV: пользователь явно выбрал игровые примеры, D-pad является основным вводом, а нативный Compose и TV-фокус имеют приоритет.

Проверяемый результат: native PNG основных состояний плюс исходный MP4, где видно изменение настройки, движение, быстрое переключение, отмену и статический вариант. Измерения плавности и нагрузки относятся к указанной сборке/устройству. Кадры 720p, 1080p и 4K сопровождаются плотностью Android; увеличение картинки не считается проверкой другого разрешения.

Внешние первоисточники: [Android TV: дистанция и D-pad](https://developer.android.com/design/ui/tv/guides/foundations/design-for-tv), [Compose for TV](https://developer.android.com/training/tv/playback/compose), [Compose animation](https://developer.android.com/develop/ui/compose/animation/quick-guide), [Emil Kowalski skills](https://github.com/emilkowalski/skills). Исходный художественный ориентир и разрешение на авторские материалы перечислены ниже.

Дата фиксации: 2026-11-08. Путь: самостоятельная реализация по выбранному пользователем существующему визуальному ориентиру. Аудит изображений выполнен через `view_image`; приложение и анимации в движении в этом исследовании не запускались. Эти материалы не доказывают работу нового APK, Twitch или аккаунта.

## Сценарии и состояния

**Каталог.** Поиск сверху рейки, настройки снизу. Активный раздел обозначен фоном и цветом значка; текущий фокус отличается от выбранного раздела. Когда фокус в рейке, карточка не должна выглядеть вторым активным фокусом. OK по карточке запускает её эфир. Back из плеера восстанавливает идентификатор карточки, раздел и прокрутку; если канал исчез, выбирается ближайший доступный сосед. Обновление данных не переносит фокус само. Пусто/ошибка/нет сети имеют понятный текст и действующий повтор. Авторские карточки используются только в явно подписанном примере настроек, а не как обычный каталог при отсутствии данных.

**Плеер.** Видео — главная поверхность. При скрытом HUD первый OK только открывает действия; он не ставит на паузу тем же событием. В live HUD компактная нижняя полоса: LIVE, канал, категория, зрители, название; справа пауза, качество, чат и кинотеатр, дополнительные реально реализованные действия. Действия с включённым состоянием имеют подпись/индикатор помимо цвета. Для записи добавляются время, линия перемотки и доступные действия записи; live не показывает ложную перемотку. Один OK в списке качества применяет вариант и закрывает панель. Back закрывает ближайший слой и восстанавливает вызвавшее действие, затем HUD, затем плеер. Длинный OK не порождает ещё и короткий OK при отпускании.

**Чат.** Уточнение пользователя для beta.7: «Чат» и «Кинотеатр» включаются независимо и взаимно исключаются. Есть три состояния: выключено, оверлей, кинотеатр. Повторное нажатие активного режима выключает его; редактирование параметров выключенного режима его не включает. Оверлей оставляет видео на весь экран и накладывает чат в выбранном углу. Кинотеатр выделяет чату отдельную правую колонку, а полное видео вписывает в остаток с сохранением пропорций. Фон, размер текста и геометрия хранятся отдельно для этих режимов. Размеры примера и настоящего чата вычисляются одной функцией из нормализованной сцены; не поддерживать вручную две похожие разметки. Новые сообщения появляются снизу, старые уходят вверх; история ограничена. Читаемость проверяется на светлом и тёмном видео.

**Настройки через пример.** При входе фиксируется сохранённое значение. Стрелки меняют только draft и немедленно перерисовывают пример. Заполненная строка показывает фокус, значение справа — черновик; подпись сообщает о несохранённых изменениях. OK/стрелки меняют параметр; отдельное «Сохранить» применяет весь черновик, Back отменяет и восстанавливает исходное состояние. В beta.7 оба профиля доступны отдельными группами, а пример неактивного режима подписан «только пример». Открытие/закрытие не сбрасывает эфир, не меняет канал, не создаёт новый плеер. Для переключателя в быстром HUD один OK может применять сразу; он не маскируется под экран с отложенным сохранением.

**Анимация примера.** Авторская сцена танка/персонажа демонстрирует оверлей, фон, размер и позицию; мини-каталог демонстрирует поведение карточек. Анимация объясняет существующее свойство: положение, размер текста, фон, режим чата и включение анимаций. Волны звука и видео-превью карточек допустимы только после реализации соответствующей функции. Только видимый пример работает; при уходе со страницы/в фон таймеры и анимации останавливаются. Быстрые стрелки немедленно прерывают переход. Отключённая системная анимация оставляет статический, но функциональный пример. Точное время цикла иллюстрации не является контрактом: важнее соответствие реальной функции и отсутствие нагрузки вне экрана.
