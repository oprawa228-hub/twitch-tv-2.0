# Навигация beta.11

## Основание

Прочитаны `START_HERE.md`, `PROJECT_BRIEF.md`, `NEXT_SESSION.md` старого read-only проекта и текущие `OprawaCatalog.js` / `OprawaFollowing.js`. Рабочий ориентир — WebView-версия 1.0.2, не остановленный Native Preview.

У старого интерфейса поиск отделён сверху; основные разделы — Каналы, Записи, Категории, Рекомендации; быстрые каналы стоят перед единственными нижними Настройками. При входе открываются подписки. Опрос подписок выполняется через 30 секунд после ответа, после ошибки — через 10 секунд. Выбранный быстрый канал удерживается при изменении порядка.

Уведомление о начале эфира показывается 4,5 секунды: аватар, имя, Go Live сообщение или «Начал эфир», категория. Ошибка опроса не сбрасывает базу обнаружения новых эфиров. Подробности и реализация tracker принадлежат root.

## Решения и реализация

1. `FollowingMonitor` — общий источник подписок для боковой панели, каталога Каналов и уведомлений. Один lifecycle-процесс опрашивает его каждые 30 секунд после успеха / 10 секунд после ошибки. Ручное обновление перезапускает этот же процесс; Home отменяет его.
2. Слева: поиск, Каналы, Записи, Категории, Рекомендации; затем прокручиваемые онлайн-подписки и закреплённые Настройки. Аккаунт и О приложении остаются внутри Настроек.
3. Панель занимает 84 dp без фокуса / 208 dp с фокусом. Свёрнуты только иконки и аватары, развёрнутая панель показывает названия. Существующие TvColors, типографика и трёхколоночный каталог сохранены. Аватары и маленькие live-точки отличают каналы от разделов.
4. Основные разделы открывают предпросмотр по устойчивому фокусу; Search и Settings — по OK/Right. Быстрый канал показывает аватар, категорию, зрителей, заголовок и реальное беззвучное видео; архив не запрашивается по наведению. OK/Right запускает эфир, длинный OK открывает канал. Back возвращает исходную страницу и карточку.
5. Явная навигация сбрасывает признак ручного hover до загрузки нового экрана и увеличивает поколение восстановления фокуса. Это охватывает OK/Right на уже показанном разделе без повторного сетевого запроса. Обновление подписок сохраняет порядок стабильных channel IDs. Удаление выбранного онлайн-канала выбирает ближайшего соседа либо раздел Каналы.
6. Вошедший пользователь начинает с Каналов, гость — с Рекомендаций. Запоздалая проверка аккаунта не перенаправляет пользователя, уже начавшего навигацию.
7. Подготовлены реальные D-pad instrumented сценарии и отдельные детерминированные проверки sidebar. Сборка, эмулятор и выпуск принадлежат root.

## Границы данных

`followedChannels()` возвращает live и offline каналы; в боковой панели видны только live. Root добавил `recordingsPage(channels, after)`: порции по 6 каналов с 3 последними публичными архивами каждого. Main фиксирует список подписок на первой странице, чтобы фоновый опрос не сдвигал cursor. Это записи подписок, без заявления о глобальной хронологии по всем каналам.

Рекомендации означают доступный каталог популярных эфиров, без заявления о персонализации. Guest-разделы Каналы/Записи объясняют необходимость входа. Пустая промежуточная страница записей предлагает «Искать дальше», а не утверждает отсутствие архивов во всём списке.

Уведомления используют root-компонент `FollowNotifications`. Main блокирует показ в фоне, настройках, аккаунте, окне выхода и при видимом HUD; уже просматриваемый канал (включая большой предпросмотр из боковой панели) исключён.

Выбор стандартной раскрывающейся TV-панели опирается на [Android TV navigation drawer](https://developer.android.com/design/ui/tv/guides/components/navigation-drawer) и [D-pad navigation](https://developer.android.com/training/tv/get-started/navigation): группировка по важности, раскрытие названий при фокусе, постоянное ясное положение фокуса, минимальное количество подтверждений.

## Проверка

`evidence/beta11-probe-build.log`: root выполнил assembleDebug, unit tests и assembleDebugAndroidTest; BUILD SUCCESSFUL за 8 секунд. Это подтверждение сборки, не успешного поведения на телевизоре.

`SidebarNavigationTest`: controlled данные, production NavigationRail/CatalogScreen, реальные D-pad события; проверяет section-focus + Right commit, сохранение выбранного канала при reorder, восстановление соседа после offline и Back к исходному каталогу, отдельные short/long OK. `CatalogFocusTest` адаптирован к новой структуре. `TvNavigationTest` выбирает Рекомендации явно и отличает заголовок каталога от одноимённого пункта панели.

`searchOpensWithTheQueryFieldFocused` воспроизвёл отсутствие фокуса поля. Main теперь запрашивает фокус поля при явном открытии поиска и запрещает пустому каталогу перехватывать его. Root подтвердил Search и удержание OK отдельным recovery-прогоном. Все три controlled SidebarNavigationTest прошли в полном прогоне.

`evidence/beta11-full-native.log`: 67 сценариев, 59 PASS / 8 FAIL. Семь остановились на старом ожидании заголовка «Ваш эфир» вместо нынешнего обзора настроек; этот test helper исправлен без изменения production. `evidence/beta11-final-navigation-native.log`: 16 сценариев, 12 PASS / 4 FAIL; все сценарии настроек прошли, но два сценария восстановления каталога обнаружили реальное смещение строки на 22–23 px, а два прервались из-за устаревшего accessibility-узла в helper.

Смещение строки оказалось production-регрессией, а не особенностью fixture: раскрытие панели меняло высоты карточек, и LazyGrid запоминал якорь для узкого каталога. CatalogScreen теперь отдельно сохраняет index/offset при уходе фокуса из сетки и восстанавливает их после возврата фокуса и схлопывания панели. Root повторил оба воспроизведения — controlled CatalogFocus и настоящий authenticated каталог с пагинацией — и получил 2 PASS за 33,103 секунды. Точное сравнение позиции осталось прежним, допуск не добавлен.

Helper при StaleObjectException повторно читает актуальный accessibility-узел в прежнем ограниченном бюджете шагов. Полный повтор 16 навигационных проверок, пересборку release и выпуск выполняет root; результаты физического ТВ здесь не заявляются.
